# 交互与文案

## 查询、排序、分页与选择

| 行为 | 交互契约 |
| --- | --- |
| 搜索 | 可清空，提示可搜索字段；名称查询通常忽略大小写并去除条件首尾空白，不改写资源原值 |
| 筛选 | 默认项明确为「全部状态」等，条件按交集组合；有条件时提供「重置筛选」 |
| 处理顺序 | 完整客户端数据先过滤、再排序、再分页；服务端分页由接口处理，当前一页不能冒充全量结果 |
| 排序 | 同列切换方向；名称自然排序，时间和大小按数值，缺失值规则稳定；不原地修改原始数组 |
| 页码 | 默认每页 `10` 条，选项 `10 / 25 / 50 / 100`；目标系统有固定约定时沿用。查询、排序或每页条数变化回第一页；删除与刷新修正越界页码 |
| 滚动 | 查询、排序和翻页后表格回顶，不移动固定头部与分页 |
| 勾选 | 仅为真实批量操作设置；以稳定唯一标识保存；表头全选只覆盖当前页可操作项，支持半选 |
| 选择清理 | 查询条件变化清除旧选择；同一查询翻页可保留，但明确总已选数量与「清除选择」；刷新剔除不存在或不可操作项 |
| 可用性 | 真实禁用无权限、状态不适用、受保护或无目标的操作，说明原因；服务端仍校验 |

查询与选择的作用范围必须一致。服务端分页若不能核实跨页选择的有效性，可选择翻页清除并明确提示；不能默认拥有全量资源。全局「选择全部匹配项」仅在接口支持且单独说明范围时提供。

有详情或创建往返时，将合法搜索、筛选、排序、分页保存在路由或项目既有状态中。校验 URL 中的枚举、页码和每页条数；按项目需要恢复滚动位置。不要把任意查询参数当业务配置。

## 导航与历史

二、三级页面用左侧「后退箭头 + 标题」。后退优先返回有效站内来源并保留查询；无历史、站外、登录、无效路由或同页查询记录时，回到最近业务父级。不能只调用浏览器后退而没有回退规则。

面包屑按业务层级导航，上级可点击，当前页为文本并标记 `aria-current="page"`。窄屏保留上级入口，必要时仅导航区横向滚动。

创建或发布成功后替换已提交表单的历史项，再进入真实详情或结果页，避免后退误入空白创建页。提交失败保持当前输入及来源上下文；导航不能绕过草稿或提交保护。

## 草稿与保存

- 以初始默认值或首次服务端回填为基线，比较实际字段、脚本、参数、文件与选择值；排除加载、错误、步骤等界面状态。还原原值即不再脏，成功保存后更新基线，失败保留基线与输入。
- 有修改时，后退、面包屑、菜单、取消、切换对象和弹窗关闭都经过同一离开保护；浏览器刷新或关闭使用原生离开确认，文案由浏览器控制。
- 放弃提示使用「继续编辑」「放弃修改」，不默认聚焦放弃。取消、关闭或 Esc 继续编辑，保留输入和滚动位置。重复导航与嵌套编辑共用一次待确认，放弃只授权本次离开。
- 同页筛选、分页等非离开行为不误报；同一路径切换实际编辑对象仍需判断是否丢弃草稿。初始回填、保存成功与只读内容不误报。
- 独立表单分别记录基线，保存一项不能清除另一项修改。退出登录、切换账号等会丢弃其他草稿的操作也要走相应保护。
- 提交前完整校验；防重锁覆盖异步校验和请求整个过程。提交中禁止重复或冲突动作，阻止会丢失提交结果的关闭与导航，不叠加放弃提示。
- 顶部原生提交按钮用 `form` 属性关联表单；组件库表单通过它的校验及提交入口处理，不直接绕过校验。保留回车提交。
- 校验说明字段、问题及正确格式；字段修正后清除失效提示。不要裁剪密码等有意义的空白。只发送本次操作合法字段，隐藏的无关配置不整体提交。
- 失败保留输入且可重试；成功后按业务关闭、刷新或进入详情。放大编辑与原区共享草稿，关闭放大窗口不会保存到服务端，也不会丢失修改。

普通可逆编辑使用保存按钮完成，不为每次保存加确认。密码与令牌默认隐藏，不通过通知、URL 或日志回显。

## 异步状态与反馈

分别维护数据、首次完成标记、加载与错误；不要用 `data.length === 0` 同时表示尚未加载、失败与真实为空。

| 状态 | 展示和恢复 |
| --- | --- |
| 首次加载 | 对应区域进度或加载层，不先闪出空状态 |
| 刷新中 | 保留旧数据，有进行中标记并防止同操作并发 |
| 真实为空 | 「暂无…」，按能力提供创建或添加入口 |
| 无查询匹配 | 「没有找到匹配的…」，提供清除搜索或重置筛选 |
| 首次失败 | 「暂时无法加载…」和重试，不能暗示资源已被删除 |
| 刷新失败 | 保留旧内容，就地显示失败与重试，必要时注明数据可能过期 |
| 局部失败 | 其他区域继续可用，不可读项显示「状态未知」「暂不可用」，不替换为零、未使用或正常 |
| 操作完成 | 真实完成后说明动作和实际数量；请求已发送不等于执行成功 |

字段错误靠近字段，表单任务错误放表单反馈区，列表错误放列表内；需要用户处理的错误持续可见。请求层与页面只负责一次通知，认证失效沿用统一处理。区分连接失败、超时、无权限和业务冲突，给出适当下一步，原始原因可放可展开详情中。

取消可取消的旧请求、定时器与订阅，或用请求标识阻止旧响应覆盖新对象；取消不报操作失败。不能取消的变更按真实执行结果处理，不伪造中止或成功；离开后不更新已卸载组件。轮询不移动用户滚动位置，不覆盖正在编辑的草稿。

## 危险操作与批量结果

1. 执行前固定目标快照，显示名称、数量与实际影响；按接口能力说明可恢复性和保护限制。删除连接配置、删除远端数据、停用功能等影响不能混用文案。
2. 确认后仅操作合法目标，跳过项说明原因；不能将普通操作悄悄升级为强制操作。
3. 逐项记录成功与失败。成功项及时更新数据与选择，失败项显示名称和原因，不把部分成功显示成整批原子成功。
4. 全部成功关闭；部分失败保留结果，提供「重试失败项」「关闭」，重试不再提交已成功项。有副作用请求不无限自动重试。

风险确认与草稿离开确认是不同目的；只在实际需要时使用。禁用原因须可读取，不能仅靠一个无法悬停或聚焦的禁用按钮提示。

## 中文文案

默认用简体中文，写清动作与对象。按钮用「动词 + 对象」，语境明确时可简化。文案描述用户任务，避免内部函数名或接口字段；技术标识、资源原名与原始日志保留。

| 场景 | 推荐文案 |
| --- | --- |
| 主要操作 | 创建项目、添加连接、保存更改 |
| 查询与选择 | 搜索名称或编号…、全部状态、重置筛选、已选 3 项、清除选择 |
| 无数据 / 无匹配 | 暂无项目 / 没有找到匹配的项目 |
| 加载失败 | 暂时无法加载项目列表；重试 |
| 请求问题 | 无法连接服务，请检查网络后重试；请求超时，请重试 |
| 批量结果 | 已删除 3 个项目；2 个项目删除失败；重试失败项 |
| 草稿 | 当前内容尚未保存，离开后将丢失修改；继续编辑；放弃修改 |
| 危险确认 | 删除项目；显示具体对象及真实影响；取消；确认删除 |
| 复制 | 复制地址；地址已复制；复制失败，请重试 |
| 未知状态 | 状态未知；必要时附服务端原值，不猜测成功 |

## 验证场景

按本次功能覆盖有意义的场景：组合查询、排序与分页边界；跨页勾选与清理；直接打开详情及往返；首次失败与刷新失败；局部不可用；校验失败与重复提交；保存失败后的离开保护；批量部分失败及失败项重试；权限或状态变化。模拟接口应注明，不能代替真实接口能力判断。

布局至少检查约 `1440px` 桌面、`390px` 窄屏，必要时覆盖 `760px` 附近和较矮视口。验证长名称、宽表、键盘焦点、浮层主题与底部操作。新增有业务意义的逻辑才补相关测试，纯文案或间距不机械增加测试。
