# 视觉与布局

## 色彩与主题

规范值是这套深色风格的默认基准。目标项目已有品牌或可访问性要求时保留语义关系并调整变量，不在各页面随意选取近似值。[CSS 主题变量](../assets/console-tokens.css)提供相同数值，采用 `--cdc-` 前缀避免与现有变量重名。

| 角色 | 默认值 |
| --- | --- |
| 页面 / 卡片 / 输入、代码区 | `#151515` / `#202020` / `#171717` |
| 表头、分隔 / 控件边框 / 悬停边框 | `#303030` / `#3b3b3b` / `#666` |
| 行悬停 / 行选中 | `#282828` / `#24343c` |
| 主文字 / 常规文字 / 次要文字 / 辅助文字 | `#ebebeb` / `#d6d6d6` / `#999` / `#888` |
| 链接 / 链接悬停 / 焦点 | `#35acd7` / `#76cdec` / `#33a7d5` |
| 主按钮背景、边框 / 文字 | `#eee` / `#262626`；悬停 `#fff` / `#111` |
| 危险按钮背景 / 边框 / 文字 | `#482427` / `#6c3439` / `#f1a7ac` |
| 危险按钮悬停背景 / 边框 / 文字 | `#673035` / `#9a4d54` / `#ffd6d9` |
| 错误背景 / 文字 | `#3c2528` / `#ffc3c8` |
| 警告背景 / 文字 | `#3a3020` / `#e6c48e` |
| 成功背景 / 文字 | `#23362b` / `#acd6bc` |
| 信息标记背景 / 文字 | `#075474` / `#d4ecf6` |

状态使用低饱和底色配文字：绿色表示可用或完成，棕黄表示提醒或维护，暗红表示异常或危险，灰色表示停止、停用或未知。实际映射取决于业务，未知不能着成功色。不要仅用颜色表达状态。

卡片边框 `1px`、圆角 `10px`；控件圆角 `4px`，命令块和选项 `5–6px`。普通卡片不靠强阴影分层；浮层保留必要阴影。避免无业务用途的渐变、横幅和大面积留白。

## 字体、间距和图标

| 元素 | 默认尺度 |
| --- | --- |
| 页面标题 | `18px / 600`，行高 `28px` |
| 卡片标题 | `15px / 600`，行高 `24px` |
| 正文 | `13px`，行高约 `20px` |
| 表头、按钮、分页、辅助数值 | `12px` |
| 次级标识、徽标、帮助说明 | `11–12px` |
| 常规图标 / 标题图标 / 排序图标 | `16px` / `18px` / `13px` |
| 控件高度 | 紧凑桌面 `32px`；复杂表单可统一为 `36px` |
| 页面内边距 / 模块间距 | 桌面 `18px 20px` / `16px`；窄屏 `12px` / `12px` |
| 工具栏内边距 / 操作间距 | `18px 20px` / `8px` |
| 表单组间距 / 字段间距 | `24–28px` / `16–22px` |

使用系统无衬线字体。命令、路径和原始数据按需等宽；对齐数值可用 `font-variant-numeric: tabular-nums`。正文保持可读，不将整个表格改成代码字体。触屏项目按其可访问性标准扩大点击区域，不机械保留桌面控件尺寸。

沿用目标项目一致的线性图标，不混入表情或不同笔画风格。图标按钮有可见焦点、中文无障碍名称，必要时补充悬停提示。标题图标可置于 `32px` 的蓝灰圆形底座中（背景 `#303844`，图标 `#c6d4e5`），只在需要区分资源类型时使用。

## 按页面用途选择骨架

| 页面类型 | 结构和操作位置 |
| --- | --- |
| 资源列表 | 标题与刷新 → 卡片工具栏 → 筛选与摘要 → 就地反馈 → 表格滚动区 → 固定分页 |
| 独立详情 | 固定顶部的返回、标题、状态和页面操作 → 下方分组卡片滚动；局部操作留在卡片或资源行 |
| 创建、编辑 | 固定顶部的返回、标题和提交 → 限宽居中的分组表单滚动 |
| 多步向导 | 顶部固定标题、步骤与当前步骤操作 → 中间表单滚动；切步后内容回顶 |
| 简短任务、确认 | 对话框；取消在前、主要动作在后，底部始终可见 |
| 保留列表上下文的复杂详情 | 抽屉；可在列表与对象详情间快速切换 |

不把所有页面强行套成列表。独立工作区的顶部栏位于内容滚动容器之外，可用弹性布局实现，不要求使用 `position: fixed`。

## 列表与滚动

工具栏左侧为卡片标题，右侧为搜索与操作；主动作排在操作组末尾。搜索宽约 `240–280px`，带前缀图标和清空入口。筛选位于下一行，选择器约 `140–180px`、间距 `10px`；右侧放业务摘要。

表头高约 `42px`、单元格横向内边距 `12px`。单行记录约 `50–54px`，双行记录约 `60–66px`，随内容决定。名称列优先分配空间，选择列约 `48px`、左侧内边距 `20px`。宽表只在自身区域横向滚动。

列表全高布局需要祖先容器提供可用高度，并贯通 `min-height: 0` 和 `min-width: 0`。以下类名仅说明结构，映射为目标项目组件或带作用域的类名后使用：

```css
.console-page {
  display: flex;
  flex-direction: column;
  flex: 1;
  min-width: 0;
  min-height: 0;
  gap: 16px;
}
.console-list {
  display: flex;
  flex-direction: column;
  flex: 1;
  min-width: 0;
  min-height: 0;
  overflow: hidden;
}
.console-table-scroll { flex: 1; min-height: 0; overflow: auto; }
.console-toolbar, .console-filters, .console-feedback, .console-pagination { flex-shrink: 0; }
.console-table thead { position: sticky; top: 0; z-index: 2; }
```

表头使用实色背景覆盖下方行，局部层级不得压过弹层。分页在卡片底部，顶部细边框，内边距约 `12px 20px`、高度至少约 `58px`；左侧总数与选择反馈，右侧每页条数与翻页。容器高度不受约束的普通文档页面，可保留自然滚动，不强造第二个滚动区。

## 详情、表单与内容

- 独立工作区默认最大宽度 `1100px`、`width: 100%`、水平居中，顶部栏与内容对齐。桌面上下留白各 `18px`，窄屏各 `12px`；模块间距不要重复叠加父级 `gap` 与子级外边距。
- 顶部左侧为后退箭头紧邻标题，右侧为状态、刷新和页面动作。箭头按钮约 `32px`、图标约 `20px`，可复用目标项目的线性箭头。长标题最多两行并提供完整值；窄屏操作换行且完整可见。
- 顶部提交按钮关联实际表单并保留回车提交与校验。操作错误放在可见反馈区域，不能藏在长表单底部。
- 键值信息使用语义表格或网格，标签宽约 `100–180px` 或 `22%–35%`，值列 `minmax(0, 1fr)`；长值 `overflow-wrap: anywhere`。业务名称优先，ID 弱化辅助定位。
- 表单按基本信息与实际配置分组。帮助文字贴近字段；同组标签对齐方式一致；双列字段在窄屏转单列。互斥选项可用边框选项卡，选中后蓝边、浅蓝字和深蓝灰底，同时保留原生选择语义。
- 列表长名称省略时提供完整读取或复制方式；错误详情不截断关键原因。缺失用 `—`，真实零显示 `0`，不可用写明原因。
- 命令块深底细边框、`12px` 等宽字并提供复制。脚本、配置和代码可提供「放大编辑」或「放大查看」，与原区域共享草稿及权限，放大窗口不是第二次保存。

## 对话框、抽屉与浮层

短确认宽约 `540px`，常规编辑约 `580px`，较复杂详情抽屉约 `820px`，都是参考值；实际不超过视口减去安全边距。内容限高并内部滚动，标题与底部操作保留。低高度视口同样能取消、提交和关闭。

浮层采用与卡片一致的深灰底、细边框、`10px` 圆角及头尾分隔。Portal / Teleport 挂载到根节点后，也必须获得主题变量与专属样式；不要用全局组件选择器覆盖所有弹窗。抽屉左右分栏在窄屏改为纵向，并限制内部导航高度。

放大代码窗口限制在视口内，若允许调整大小，提供键盘操作方式并保持关闭入口可见。关闭后焦点回到打开入口，草稿不丢失。

## 响应式与可访问性

- 约 `1100px`：工具栏内边距缩为 `12px 16px`，搜索可缩到 `230px`，减少次要摘要。
- 约 `760px`：页面边距与模块间距 `12px`，工具栏、筛选和顶部操作换行，双列转单列。
- 约 `480px`：搜索或分页计数可独占一行；不隐藏创建、保存、取消等关键操作。
- 弹性子项设置 `min-width: 0`，宽表局部滚动，操作允许换行；检查滚动条旁的边框与按钮没有被裁切。
- 滚动区可聚焦且有名称，使用实际表格、表单、按钮、链接和对话框语义；排序、选择、加载和选项状态对辅助技术可见。对话框管理焦点，禁用态使用真实属性并可获知原因。
- 尊重减少动态效果偏好；刷新动画只在请求进行时显示。按目标项目标准检查实际字号、颜色组合和焦点对比度，不能仅凭这张色表声称满足可访问性标准。
