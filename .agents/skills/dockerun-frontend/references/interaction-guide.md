# 交互与中文规范

## 查询、排序、分页与选择

以 [Containers.vue](../../../../frontend/src/views/Containers.vue)、[Networks.vue](../../../../frontend/src/views/Networks.vue)、[Volumes.vue](../../../../frontend/src/views/Volumes.vue) 和 [Registry.vue](../../../../frontend/src/views/Registry.vue) 为列表行为入口，查询状态及纯逻辑参考对应的 `frontend/src/utils/` 文件。

| 行为 | 规则 |
| --- | --- |
| 搜索 | 搜索框可清空，中文占位文字明确可搜索的字段；名称、ID、镜像、地址等范围以业务为准。名称查询通常忽略大小写并去掉搜索条件首尾空白，不改写资源原值。 |
| 筛选 | 有明确的「全部状态」「全部驱动」等默认项及占位文字；多个条件按交集组合。有条件时提供「重置筛选」。 |
| 执行顺序 | 对完整且已确认的可查询数据先过滤、再排序、再分页。服务端分页时使用真实查询能力，不把已加载的一小页伪装成全量筛选结果。 |
| 排序 | 再次点击同一列切换方向，切换列采用适合该字段的默认方向；时间和大小按数值排序，名称采用自然排序，正确处理缺失值。排序不能修改原始数据数组。 |
| 页码 | 默认每页 `10` 条，选项为 `10 / 25 / 50 / 100`，显示每页条数与前后翻页。查询条件、排序字段或每页条数变化后回第一页；删除、刷新后将页码限制在有效范围。 |
| 滚动 | 翻页、排序和查询变化后把表格滚动到顶部，保留页面头部与分页位置。 |
| 选择 | 只在有批量操作时添加选择列，以稳定 ID 或资源唯一名称保存选择。表头全选只覆盖当前页可操作项，支持半选。 |
| 选择清理 | 更改搜索/筛选条件时清除旧选择；同一查询的翻页可保留选择，但应明确显示总已选数量与「清除选择」。刷新后剔除不存在或已不可操作的项。 |
| 操作可用性 | 没有符合条件的目标时禁用操作；解释是未选择、状态不支持、无权限还是资源受保护。禁止仅通过降低透明度模拟禁用。 |

有详情或创建页面往返时，沿用现有 `read…ListState` / `…ListQuery` 模式，把合法的查询状态传到路由再带回列表。校验页码、每页条数、排序字段和枚举值；不要把任意 URL 参数直接作为业务配置。仅当任务确有必要时扩展已有路由，不为使用本规范改变业务导航。

## 面包屑与后退

- 面包屑复用 `utils/navigation.ts` 的业务层级，覆盖列表、详情、创建、发布向导及容器工作区；上级使用真实路由链接，当前页为带 `aria-current="page"` 的文本。首页链接按管理员/普通用户指向概览或内置仓库。
- 二、三级页面采用「后退箭头 + 标题」居左、操作与状态居右的顶部结构。箭头使用 `PortainerIcon` 的 `back` 图标及中文名称和提示，不再在右侧重复放「返回列表」文字。
- 箭头优先返回 Vue Router 记录的有效站内来源页，保留原 URL 的查询条件；没有历史、历史为登录或外部页面、未知路由、仅同页查询变化时，返回最近业务父级。面包屑始终按业务层级跳转，不受浏览历史影响。
- 创建/发布成功后替换已提交表单的历史项，避免后退到空白创建页后重复提交；提交失败保留输入。提交期间禁用后退按钮，并沿用路由离开保护，面包屑也不能绕过已有保护。
- 创建、编辑和发布页通过 `useUnsavedChanges` 保护未保存的草稿，统一覆盖标题后退、面包屑、侧栏菜单、取消及浏览器前进/后退。确认弹窗使用「继续编辑」「放弃修改」，不默认聚焦放弃按钮，避免回车误丢弃；取消、关闭或按 Esc 均留在当前页，保留表单与滚动位置。重复导航和嵌套编辑只出现一次待确认窗口。
- 基线取初始值或服务端首次回填值；仅比较实际表单、脚本、参数、附加文件和选择值，排除加载状态、错误、预检查结果、步骤序号等界面状态。改回原值恢复未修改；保存/创建/发布成功后更新基线，失败不更新。确认放弃只授权本次导航，后续导航被其他守卫阻止时不能误标已保存。
- 查询条件变化且同一路径的页面仍然保留时，不因筛选或分页弹出放弃确认；切换资源或页面才进行路由离开判断。提交期间阻止离开，不叠加放弃提示。浏览器刷新、关闭或跳往站外由原生离开确认保护，文案由浏览器提供。
- 窄屏面包屑另起一行，长路径仅在导航区域横向滚动，不能撑破整页或隐藏上级入口。

## 加载、空状态与反馈

为异步数据分别管理加载、错误、已加载状态和业务数据。刷新有进行中状态；禁止刷新或提交同一操作时叠加重复请求。

- 首次加载：在对应区域展示加载层或进度，避免先闪出「暂无数据」。刷新图标只在加载时旋转。
- 普通刷新：保留原内容，成功后更新数据；失败保留原内容并在对应卡片显示错误及「重试」。
- 真正无数据：说明当前没有该资源，按能力提供「创建…」「添加…」「查看使用方法」等下一步。
- 无搜索结果：显示「没有找到匹配的…」，提供「重置筛选」或「清除搜索」。
- 加载失败且没有旧数据：显示「暂时无法加载…」，与正常空状态区分；不要暗示用户需要重新创建资源。
- 局部失败：可用区域继续显示，对不可用信息标记「状态未知」「暂不可用」等，并给出相关重试入口；不要把未知值替换为零、未使用或正常。
- 成功反馈：用简短中文消息说明完成了什么，有多项时带实际成功数量；不以发出请求代替成功。
- 失败反馈：字段错误靠近字段，任务错误放在表单内，列表错误放在列表内。需要保留的错误不要只使用会自动消失的通知。

请求层已有错误通知时，按当前项目的 `silentError` 模式避免重复弹出同一个错误；认证失效仍沿用统一认证处理。区分超时、连接失败、无权限和业务冲突，以中文给出下一步；原始错误按需保留供排查。

卸载页面时取消可取消的请求、订阅和定时器。切换抽屉对象、标签或版本时取消旧请求，或用请求标识阻止旧响应覆盖新选择；取消请求不显示成操作失败。对正在完成且不能取消的变更，离开页面后也不得再更新已卸载界面。

## 表单与保存

以 [NetworkCreate.vue](../../../../frontend/src/views/NetworkCreate.vue)、[VolumeCreate.vue](../../../../frontend/src/views/VolumeCreate.vue)、[RegistryDetail.vue](../../../../frontend/src/views/RegistryDetail.vue) 为复杂配置参考。账号编辑可参考 [UserEditorDialog.vue](../../../../frontend/src/components/users/UserEditorDialog.vue)。

- 先呈现用户必须决定的基本信息，再分组呈现高级配置；根据驱动、类型或权限显示适用字段和解释。
- 校验提示明确说明字段、问题和可接受格式。长度、大小、字节等单位与接口一致；密码等有意义的空白不能擅自裁剪。
- 必填信息缺失或没有变更时，按业务情况禁用提交；提交前执行完整校验。修正后及时清除过时错误，避免保留与当前值不符的红色提示。
- 提交过程中显示加载，禁止重复提交和冲突操作；表单校验为异步时也要防止两个提交同时穿过校验。
- 短任务弹窗明确区分取消与提交；提交或删除过程中锁定会中断任务的关闭入口。长表单提交期间采用已有路由离开保护，不额外阻止正常查看。
- 失败保留用户输入并允许重试；成功后关闭弹窗、更新相关数据或进入新资源详情，带回原来的列表上下文。
- 独立长表单的标题、返回与主要操作固定在顶部，滚动到任意位置均可操作；顶部按钮沿用原有校验、加载、防重复提交及离开保护。提交或加载错误放在顶部反馈区，避免在表单底部操作后看不到结果；发布向导切换步骤后将表单区域滚回顶部。
- 原生表单的顶部提交按钮使用 `form` 属性关联实际表单，保留必填校验和回车提交，不用直接调用提交函数绕过浏览器校验。
- 放大编辑与原编辑区使用同一份表单草稿，修改即时同步，关闭放大窗口不丢失内容；明确提示仍需保存表单或提交发布才生效。放大查看保持只读，不绕过父级编辑器的禁用状态；嵌套弹窗关闭后保留外层表单。
- `FormDialog` 的编辑任务绑定 `draft`，自动以每次打开时的数据为基线，关闭按钮、Esc 和取消均先检查修改；只读预览、日志、执行输出及确认删除不绑定草稿。保存成功后由父级正常关闭，不再重复确认；附加文件应用到脚本后，父级脚本仍保持未保存保护。
- 用户创建、授权与密码等自定义编辑弹窗也须接入 `useUnsavedChanges`，通过 `before-close` 保护关闭按钮与 Esc，取消按钮复用同一检查；每次打开完成回填后设置基线，保存成功先更新基线再关闭或重新登录。目标主机创建成功后的凭据展示属于已保存状态，不重复提示放弃。
- 同页多个独立表单分别记录基线，例如个人账号的密码和自动化令牌；保存一项不能清除另一项的未保存状态。修改密码会强制重新登录时，先确认另一项未保存内容，接口失败继续保留保护，成功后再清除草稿状态并跳转。
- 只发送当前操作需要的合法字段。隐藏的无关配置不随表单对象整体提交；权限修改和密码重设等影响不同的任务分别处理。
- 密码、访问令牌等敏感值默认隐藏；不在通知、URL、日志或预览中回显真实密钥。

普通、可逆的编辑使用明确的保存按钮即可；不可逆删除、强制终止等在执行前展示确认。确认文案应具体到资源、数量与实际影响，不将每次操作都变成额外的重复确认。

## 危险操作与批量结果

参考 [NetworkDeleteDialog.vue](../../../../frontend/src/components/networks/NetworkDeleteDialog.vue)、[VolumeDeleteDialog.vue](../../../../frontend/src/components/volumes/VolumeDeleteDialog.vue)、[RegistryDeleteDialog.vue](../../../../frontend/src/components/registries/RegistryDeleteDialog.vue)。

1. 打开确认时固定目标快照，展示对象名称和数量，说明真实影响及受保护规则；确认后才执行。
2. 操作按适用条件筛出目标，跳过项要说明原因。禁止自动将普通删除升级为强制删除来消除报错。
3. 记录每项结果；成功项立即反映到列表和选择状态，失败项保留名称与原因。除非业务支持可靠回滚，否则不能显示为整批原子成功。
4. 全部成功后关闭确认；部分失败时保留结果，提供「重试失败项」和「关闭」，已成功项不再提交。
5. 只对用户明确重试的失败项再次执行，或采用既有的受限重试机制；不对有副作用的请求无限自动重试。

## 五类基准页面的业务差异

以下规则体现现有页面的语义，应在修改对应功能时复核当前工具函数和服务端实现，不能机械推广成所有页面的限制。

| 资源 | 保留的交互与约束 |
| --- | --- |
| 容器 | 用组合操作组和行内快捷入口承载启动、停止、重启、暂停、恢复、日志、控制台等实际能力。按运行状态判断适用操作；普通删除要求先停止，批量操作说明跳过数量。删除容器与删除数据卷的影响不同，确认文案不能混淆。 |
| 网络 | 系统网络与 Swarm 的入口网络受保护；已连接容器时不能直接删除。详情展示关联容器和地址配置，连接/断开采用真实接口与状态。IPv4、IPv6、子网和网关的校验与配置提交一致。 |
| 卷 | 被容器引用的卷不能普通删除，包含已停止容器的引用。「未使用」必须有可靠引用数据；引用查询失败显示未知并隐藏误导标记。删除会永久移除卷中数据，使用明确的危险确认。 |
| 外部仓库 | 搜索、类型/认证/默认仓库筛选与浏览镜像入口共同服务于连接管理。删除的是连接配置，不删除远端镜像。认证密码保持掩码；保留密码、更新密码和清空密码必须遵循接口语义。 |
| 内置仓库 | 顶部显示仓库地址、当前权限和维护状态；镜像与最近提交采用分段视图。选择镜像打开标签/版本抽屉，支持复制完整引用和拉取命令。只读维护仍允许浏览和拉取，禁止推送与删除。删除清单按摘要影响关联标签，当前及保留发布版本受保护。 |

可复用部件包括容器的 `ContainerActionGroup` / `CompactItems`、网络和卷的键值编辑器、各领域删除弹窗、内置仓库的标签版本抽屉与客户端使用弹窗。复用前确认其业务假设适合当前页面；不为了统一名称而将不同接口行为硬塞进一个组件。

## 中文文案

面向用户采用简体中文，写清楚动作和对象。按钮通常使用「动词 + 对象」或已有明确语境下的动词，避免将实现细节当作操作名称。

| 场景 | 推荐文案 |
| --- | --- |
| 资源列表标题 | 容器列表、网络列表、卷列表、外部仓库列表、镜像列表 |
| 主要操作 | 创建网络、创建卷、添加仓库、创建用户、保存更改 |
| 查询 | 搜索名称、ID 或子网…；全部状态；全部驱动；重置筛选 |
| 空状态 | 暂无网络；仓库中还没有镜像；没有找到匹配的用户 |
| 加载失败 | 网络列表加载失败：…；暂时无法加载镜像列表；重试 |
| 网络连接失败 | 无法连接服务，请检查网络后重试 |
| 超时 | 请求超时，请重试 |
| 批量结果 | 已删除 3 个网络；2 个卷删除失败；重试失败项 |
| 选择反馈 | 共 25 个网络；已选 3 项；清除选择 |
| 复制 | 复制仓库地址；拉取命令已复制；复制失败，请重试 |
| 确认 | 删除卷；确认删除；取消 |
| 状态 | 运行中、已停止、暂停中、启用、停用、只读维护中、状态未知 |

技术术语的界面表达按需要采用：镜像仓库、应用栈、命名空间、驱动、身份认证、手动连接、挂载路径、摘要（Digest）、镜像清单（Manifest）、地址分配（IPAM）。Docker、Docker Hub、GitLab、IPv4、IPv6、URL、ID 等品牌和技术标识可以保留。

历史页面里的 `Registries`、`添加 Registry` 等通用英文界面文案不是新页面的模板，应写为「外部仓库列表」「添加仓库」。协议字段、API 参数和用户资源名称保持原文；原始日志与命令原样展示，周边标题、帮助和操作按钮为中文。未知的服务端状态不能任意翻译成成功，应显示「未知状态」并按需附原值。

## 验证重点

按改动范围验证下列有意义的行为，不为每个页面机械补齐相同数量的测试：

- 查询组合、自然/数值排序、分页边界、可操作项选择及返回后上下文。
- 普通成功、连接或业务失败、刷新保留数据、局部失败与重试范围。
- 表单校验、重复提交、维护和权限约束、不可逆操作实际影响。
- 约 `1440px` 桌面与 `390px` 窄屏，必要时覆盖 `760px` 附近及较矮视口；长名称、宽表、工具栏主要按钮、弹窗底部操作不被裁切。
- 键盘可进入滚动区、图标操作和分段视图；排序、选择、标签页和加载状态有正确语义；用户界面和无障碍名称为中文。

接口模拟可以用于可重复的视觉与交互验证。使用真实环境验证时，在当前任务授权范围内操作，不为测试无关场景修改真实账号、资源或发布版本。只修改本技能与说明文件时，验证文档链接、元数据与规则一致性即可。
