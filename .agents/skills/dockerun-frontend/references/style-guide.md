## 颜色与层级

| 角色 | 规范值 | 使用方式 |
| --- | --- | --- |
| 页面背景 | `#151515` | 工作台主内容区 |
| 卡片背景 | `#202020` | 列表、详情、表单卡片及新弹窗的基础色 |
| 输入框、命令块 | `#171717` | 可编辑控件与代码区域 |
| 表头、主要分隔 | `#303030` | 表头背景、卡片和行边框 |
| 控件边框 | `#3b3b3b`，必要时 `#414141` | 输入框、选择器和选项边框 |
| 悬停行 | `#282828` | 列表行悬停 |
| 已选行 | `#24343c` | 批量选中状态 |
| 主文字、常规文字 | `#ebebeb`、`#d6d6d6` | 页面主体与普通内容 |
| 次要、辅助文字 | `#999`、`#888` | 摘要、说明、标识符和缺失值 |
| 链接、链接悬停 | `#35acd7`、`#76cdec` | 可进入详情的名称与文字操作 |
| 焦点和主色变量 | `#33a7d5` | 控件焦点、活动排序与选项边框 |
| 主操作 | 背景/边框 `#eee`，文字 `#262626` | 创建、添加、保存等主要任务 |
| 删除操作 | 背景 `#482427`，边框 `#6c3439`，文字 `#f1a7ac` | 常规删除入口；容器操作组可保留其既有暗红变体 |
| 错误区域 | 背景 `#3c2528`，文字 `#ffc3c8` | 就地错误与失败列表 |
| 警告区域 | 棕色深底，如 `#3a3020`，文字 `#e6c48e` | 维护、能力受限和风险说明 |

卡片使用 `1px` 边框和 `10px` 圆角；输入框为 `4px` 圆角；分组选项、命令块为 `5–6px`。避免同级卡片混用明显不同的灰底、圆角或阴影。浮层可保留必要阴影，普通内容卡片靠边框区分。

状态颜色表达语义：绿色表示运行/启用/可用，棕黄表示暂停/维护/提醒，暗红表示异常或危险，灰色表示停止/停用/未知等中性状态。结合中文状态文字或图标，不只依赖颜色；「未知」不能显示成成功或未使用。

## 字体、密度与图标

| 元素 | 基准 |
| --- | --- |
| 页面一级标题 | `18px`、字重 `600`、行高约 `28px` |
| 卡片二级标题 | `15px`、字重 `600`、行高约 `24px` |
| 正文 | `13px`，说明性段落行高 `20px` 或 `1.7–1.8` |
| 表头、按钮、分页、表格辅助数值 | `12px` |
| 次级标识、徽标、帮助说明 | `11–12px` |
| 图标 | 常规 `16px`，标题图标 `18px`，排序 `13px` |
| 标题图标底座 | `32px` 圆形，背景 `#303844`、图标 `#c6d4e5` |

使用系统无衬线字体。命令、路径、摘要和原始数据按需使用等宽字体；日期、地址和数值可用 `font-variant-numeric: tabular-nums`。不把所有表格正文改成代码字体。

优先使用已有 `PortainerIcon` 和项目现有的 Element Plus 图标。不要混入表情图标或另一套不协调的图标。图标按钮补充中文 `aria-label`，必要时提供中文提示。

## 列表页面结构与滚动

页面顶部为 `h1` 与右侧刷新按钮；列表卡片内从上到下排列工具栏、筛选行、反馈区、表格、分页。

- 页面边距 `18px 20px`，模块纵向间距 `16px`。
- 工具栏内边距 `18px 20px`，标题与操作组间距 `16px`，操作组内间距 `8px`；按钮高度一般 `32px`。
- 搜索框放工具栏右侧操作区，宽度约 `240–280px`，带搜索前缀与清空入口。容器的组合操作组可沿用现有排列。
- 筛选行位于工具栏下一行，左右边距 `20px`、底部 `16px`；选择器约 `140–180px`，间距 `10px`。右侧放「运行中 / 全部」「启用认证 / 全部」等实际摘要。
- 卡片标题、筛选与分页保持可见；表格区域单独滚动。外层页面、卡片、表格容器形成连续的 `flex` 布局，逐层设置必要的 `min-height: 0` 和 `min-width: 0`。
- 表格使用稳定列宽，名称列优先分配空间，长内容在单元格内处理；宽表允许表格区域横向滚动，不能撑破整页。
- 表头高约 `42px`、单元格左右内边距 `12px`；选择列宽 `48px`，左内边距 `20px`。
- 单行资源记录高约 `50–54px`；包含名称与标识、权限说明的双行记录可为 `60–66px`。行高随信息密度决定，不把所有页面机械固定成同一值。
- 表头采用 `position: sticky; top: 0`，用合适的局部层级覆盖滚动行；不与弹窗、下拉层争用极高层级。
- 分页位于卡片底部，顶部细边框，内边距 `12px 20px`，高度至少约 `58px`。左侧总数、已选数量及清除选择，右侧每页条数和翻页。

弹性滚动的最小结构如下，类名按领域命名：

```css
.resource-page { display: flex; flex-direction: column; flex: 1; min-width: 0; min-height: 0; gap: 16px; }
.resource-card { display: flex; flex-direction: column; flex: 1; min-height: 0; overflow: hidden; }
.resource-table-scroll { flex: 1; min-height: 0; overflow: auto; }
.resource-toolbar, .resource-filters, .resource-feedback, .resource-pagination { flex-shrink: 0; }
```

示例类名用于说明布局关系；实际源码沿用所在领域的类名前缀，避免新增无作用域的通用选择器。

## 名称、数值和操作呈现

- 主名称为蓝色链接或按钮，可进入详情；辅助 ID、用户名、来源或路径置于次行，弱化色彩。
- 长名称使用省略号并提供完整值的提示或可复制入口。详情和错误区域用 `overflow-wrap: anywhere`，避免将关键错误截断。
- 缺失值默认用 `—`，无数据或不可用时给出对应中文说明；真实数值为零时显示零。
- 多个地址、端口、标签优先采用紧凑多行或「查看更多」；展开后保留完整值。
- 操作文字用蓝色；危险操作用暗红按钮。紧密相关的容器启动、停止、重启等操作可用已有组合按钮，保持分组边框与禁用提示。
- 状态徽标为低饱和背景、小字号和约 `10–12px` 圆角；只在语义必要时使用，不为每列添加彩色标签。

## 详情、表单与配置选择

详情按业务分组为卡片，标题与必要操作同一行。键值区用双列网格或语义表格，标签宽约 `100–180px` 或容器的 `22%–35%`，数值列为 `minmax(0, 1fr)`；长值能换行。关联容器、网络、卷或镜像提供真实导航。

表单分为基本信息、驱动/类型、地址或挂载配置、高级选项等实际分组；组间距约 `24–28px`，控件间距约 `16–22px`。短表单可使用顶部标签，配置页可使用对齐的左侧标签；同一组内保持一致。

控件高度以 `32px` 为基线，复杂编辑表单可统一为 `36px`。帮助文字紧跟对应字段；两列地址配置在窄屏改为一列。键值编辑采用「名称、值、移除」的紧凑布局。底部操作通常右对齐：取消在前，主要提交在后。

仓库供应商、用户角色等互斥配置可采用边框选项卡：默认深灰底和细边框，选中后使用浅蓝文字、蓝边框与深蓝灰背景。选中状态同时可被键盘和辅助技术识别。

## 弹窗、抽屉与代码区域

- 简短确认弹窗以 `540px` 左右为参考；编辑弹窗可为 `580px`，按内容决定，不固定所有弹窗同宽。
- 弹窗使用深色背景、细边框和 `10px` 圆角，头部与底部用分隔线；宽度不得超过视口减去两侧安全边距。
- 检查 `append-to-body` 等传送场景：页面内的作用域样式及变量不会自然覆盖所有浮层。用专属类名及实际背景设置确保主题生效，避免修改全局 `.el-dialog` 波及其他页面。
- 内容限制高度并内部滚动，取消与提交按钮始终可见；使用居中布局或合适的顶部留白，低高度视口也可操作。
- 保留列表上下文的复杂详情使用抽屉。参考内置仓库约 `820px` 的标签版本抽屉：左侧标签导航、右侧版本详情和底部操作；窄屏转为纵向布局。
- 命令块采用 `#171717` 深底、细边框、`12px` 等宽文字和明确的「复制」入口。原始清单或详细日志按需折叠，主要操作先展示用户需要的业务信息。

## 响应式与可访问性

- 约 `1100px`：工具栏边距降为 `12px 16px`，搜索框可缩到 `230px`，减少次要摘要。
- 约 `760px`：主内容边距和模块间距降至 `12px`；工具栏、筛选与操作允许换行；双列表单转为单列。
- 约 `480px`：搜索与按钮按可用宽度分配或另起一行；分页计数可独占一行。不要隐藏主要操作来换取排版空间。
- 内置仓库抽屉约 `600px` 时改为上方标签、下方详情，标签列表有自己的有限高度。
- 工具栏弹性子项设置必要的 `min-width: 0`；窄屏搜索框按需使用 `flex: 1 1 0; width: 0`，确保「创建」「添加」按钮完整可见。允许换行或局部滚动，但不裁切按钮。
- 表格滚动区可聚焦且有中文名称；排序状态、加载状态和选择状态使用相应语义属性。键盘焦点清晰，状态不只靠颜色。
- 尊重减少动态效果的偏好。刷新旋转等状态动画只在操作进行中显示。
